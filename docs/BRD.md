## 1. 배경 (Background)

개인 사용자가 친구와 공유해 쓸 수 있는 가벼운 한국어↔영어 음성 번역 앱이 필요했다. 기존 상용 앱은 설치·로그인·광고 부담이 있고, 직접 만든 앱은 링크 하나로 바로 열 수 있어야 한다는 요구가 있었다.

초기 버전(브라우저 내장 음성인식 + 무료 번역 API)을 사용해 보니, 사람이 말하는 도중 잠시 멈추면 문장이 끊긴 것으로 인식되어 번역이 어색해지는 문제가 확인되었다. 이를 해결하면서도 비용은 0원을 유지해야 했다.

## 2. 비즈니스 목표 (Business Objectives)

| # | 목표 | 측정 방법 |
|---|---|---|
| BO-1 | 친구가 링크만 열어 즉시 사용할 수 있는 공개 웹앱 제공 | 설치·로그인 없이 URL 접속으로 동작 |
| BO-2 | 운영 비용 0원 유지 | 월 청구액 0원 (GitHub Pages·Cloudflare·Groq 무료 한도 내) |
| BO-3 | 말하는 중간 멈춤에도 자연스러운 문장 번역 | 멈춤 포함 발화의 번역 결과가 원문 의도와 일치 |
| BO-4 | iPhone 홈 화면 앱처럼 사용 가능 | 홈 화면 추가 시 전용 아이콘·전체화면 동작 |

## 4. 범위 (Scope)

### 포함 (In scope)
- 한국어↔영어 양방향 음성 번역 (탭으로 녹음 시작, 재탭으로 종료·번역)
- 번역 결과 음성 출력(TTS), 복사
- 텍스트 직접 입력 번역
- 공개 URL 배포(GitHub Pages), iPhone 홈 화면 앱 지원(아이콘·매니페스트)
- API 키를 숨기는 무료 서버(Cloudflare Worker)와 무료 음성인식·LLM 번역(Groq)
- 서버 미설정 시 브라우저 내장 방식으로 자동 폴백

### 제외 (Out of scope)
- 한국어·영어 이외 언어
- 사용자 계정, 번역 이력 저장
- 실시간 동시통역(말하는 도중 번역 출력)
- 앱스토어 배포(네이티브 앱)
- 상업적 서비스 수준의 SLA, 대규모 트래픽

## 5. 성공 기준 (Success Criteria)

- 친구가 URL을 열어 마이크 버튼 두 번 탭으로 번역 결과를 소리로 들을 수 있다.
- 중간에 "음…" 하고 멈추는 발화도 하나의 자연스러운 문장으로 번역된다.
- 월 비용 0원.
- iPhone에서 홈 화면 앱으로 추가하면 전용 아이콘이 표시되고 전체화면으로 열린다.

## 6. 제약 조건 (Constraints)

| 구분 | 내용 |
|---|---|
| 비용 | 유료 구독·종량제 결제 없이 무료 한도만 사용 |
| 보안 | API 키는 브라우저·저장소에 노출되지 않아야 함 → 서버 비밀값으로만 보관 |
| 플랫폼 | iPhone Safari(홈 화면 모드) 우선, Chrome/Edge 데스크톱 지원 |
| 호스팅 | 정적 호스팅(GitHub Pages) + 서버리스(Cloudflare Workers) |
| 개발 도구 | JavaScript(프론트/워커), 빌드 도구 없음 |

## 7. 가정 (Assumptions)

- Groq 무료 한도(음성인식 1일 약 2시간 분량)는 개인 2~3명 사용에 충분하다.
- Cloudflare Workers 무료 한도(1일 10만 요청)는 초과할 일이 없다.
- 사용자는 Groq·Cloudflare 계정을 직접 만들고 키를 등록할 수 있다.

## 8. 리스크 (Risks)

| 리스크 | 영향 | 대응 |
|---|---|---|
| Groq가 모델 이름을 변경·종료 (2026-09-04 실제 발생) | 번역 실패 | 모델 후보 목록으로 자동 전환, `/models` 진단 경로 제공 |
| iPhone 홈 화면 모드에서 마이크 접근 제한 | 음성 입력 불가 | 상태 줄에 원인 표시, 필요 시 Safari에서 열도록 안내 |
| 무료 한도 초과 | 일시적 실패 | 브라우저 내장 방식으로 폴백 가능(`config.js` 주소 비우기) |
| 무료 서비스 정책 변경 | 서비스 중단 | 대체 무료 제공자(Deepgram 크레딧, Google 무료 할당량) 검토 |
